このサイトについて

AIの地図は、社会人がAIを「なんとなく」ではなく、仕組みと条件を踏まえて使えるようになるための 学習ガイドです。製品ニュースの追跡ではなく、長く使える地図を持つことを目的にしています。

編集方針

特定の製品やベンダーを推奨するのではなく、判断の基準を提示します。モデルの比較では 「総合的な最強」を一つに決めず、タスク・測定条件・予算・実行環境ごとに見方を変えます。 性能の話と、価格・速度・権限・安全性の話を混ぜないようにしています。

本文は、できるだけ一次情報と公的な技術文書に基づきます。数値やランキングは取得日を明記し、 変わらない原理と、変わりやすい比較データを分けて扱います。図は内容に応じて Mermaid のフローチャートと、文章による構造化を使い分けます。

読者として想定する人

生成AIを業務で使い始めた社会人、AI関連の提案を読む立場の人、社内導入の判断に関わる人。 プログラミングの前提知識は必要ありませんが、言葉を正確に使いたい人向けです。

ページの構成

1章を複数の短いページに分割しています。各ページは「3行まとめ」から始まり、 図・例・深掘り・誤解しやすい点・クイズ・出典で構成されます。

用語辞典

各用語を「ひとことで」「厳密には」「よくある誤解」の3層で定義し、関連する章と 用語へ相互参照します。本文中の下線付きの語からも開けます。

クイズ

正解を表示するだけではなく、選んだ選択肢に応じて正誤と解説が展開します。 章末の確認と、ランダム5問の復習の2種類があります。

モデルデータの更新

モデル比較の表は、公開APIから取得した価格・コンテキスト長・重み公開状況を元にしています。 取得したデータはすぐには公開せず、次の流れで確認してから反映します。

  1. npm run fetch:models で OpenRouter Models API から取得し、data/staging/model-comparison.json にだけ書き出す。
  2. 取得日、モデルID、価格の単位（100万トークンあたり）、コンテキスト長を確認する。 為替やキャンペーン価格ではなく、APIの表示値をそのまま使う。
  3. npm run validate:data -- --staging で必須項目と鮮度を検証する。
  4. 差分を確認し、説明文を更新してから data/model-comparison.json へ反映する。 反映後に npm run build で表示を確認する。

現在の確認日は 2026年10月27日、取得元はOpenRouter Models APIです。価格は入力・出力とも100万トークンあたりの米ドル表示で、各社の公式価格や契約条件とは 異なる場合があります。モデルの追加・廃止・価格改定は速いため、表の数値は購入判断の前に 必ず提供元で再確認してください。

主な参照元

本文の理解には、次のような一次資料・公開文書を参照しています。個別のページには、 そのページで直接使った資料を「出典・参考資料」として掲載しています。

  • 各モデル提供元の公式ドキュメント、APIリファレンス、技術ブログ
  • Transformer に関する原論文と、Attention の解説資料
  • トークン化・埋め込み・推論に関する公開実装とドキュメント
  • エージェント、ツール利用、MCP に関する仕様と実装資料
  • モデル比較の公開データ（OpenRouter Models API など）

技術構成

本サイトは Astro による静的サイトです。本文は Markdown / MDX で管理し、[[用語]] と [[ch:04/slug]] の記法をビルド時に解決しています。 存在しない用語・章・ページへの参照はビルドを止めるため、リンク切れのまま公開されません。 検索はビルド時に生成した search.json をブラウザで照合します。

更新と訂正

誤記や古くなった記述を見つけた場合は、該当ページの更新日を変更します。 比較データは取得日を明記し、四半期を目安に見直します。原理的な説明と、 一時的なランキングや価格を同じ粒度で扱わないことが、このサイトの基本方針です。
