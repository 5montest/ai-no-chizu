はじめての方へ

いま必要なところから、読む。

全32章を順番に読む必要はありません。まずは次の基本を押さえ、目的に合う4ページを選んでください。数式やプログラミングの章は、仕組みを詳しく知りたいときに使えます。

仕事で使う前に覚えること

  1. 会社で認められたサービスとアカウントを使い、入力してよい情報を確認する。
  2. 依頼には目的・読み手・材料・出力形式を書く。
  3. 返ってきた文章の事実、数字、出典を原資料で確かめる。
  4. 送信やデータ更新を任せるときは、権限・確認者・止める条件を決める。

目的に合う4ページを選ぶ

各ページの「3行の要点」と図で全体をつかみ、詳しく知りたい節を読んでください。ルートを途中で切り替えても構いません。

01 業務で使い始めた方

まず、一つの仕事で試す

依頼の書き方と、返ってきた内容の確かめ方を押さえます。

  1. 生成AIは地図のどこにいるのか8分

    生成AIができることと、保証しないことを知る

  2. 何をしてほしいかを、どう伝えるか9分

    目的・材料・形式をそろえて依頼する

  3. もっともらしい嘘はなぜ生まれるか9分

    自然な文章に含まれる誤りを見つける

  4. 入力と権限の両方を絞る10分

    入力する情報と、許す操作を確認する

読み終えたら：資料を渡して下書きを頼み、原文と照合して使える。

02 AIの提案を読む方

用語を分けて、提案を読む

モデル・製品・検索・エージェントの違いを、提案を読む判断材料にします。

  1. モデルとサービスは別物である8分

    モデルと、アプリやサービスを区別する

  2. モデルに覚えさせず、その場で調べさせる9分

    社内文書を検索して答える仕組みを知る

  3. エージェントは何を繰り返すのか9分

    エージェントが作業を進める流れを知る

  4. ベンチマークは何を測っているのか10分

    性能の数字に付いている条件を読む

読み終えたら：何の機能を提案され、どの条件で性能を比べたのか質問できる。

03 社内導入を判断する方

効果・費用・運用を確かめる

対象の仕事を絞り、試験導入で何を測り、誰が運用するかを決めます。

  1. その仕事はAIに向いているか7分

    AIに任せる工程を決める

  2. 評価は用途ごとに作る9分

    実際の仕事で品質を測る

  3. コスト比較シートを作る14分

    利用量と確認作業を含めて費用を比べる

  4. 運用し続けるための設計6分

    更新・停止・問い合わせの担当を決める

読み終えたら：導入判断の確認シートに、条件・担当・未確認事項を残せる。

導入判断の確認シートへ →

まずは、短い社内連絡の下書きで試す

以下は架空の例です。公開情報だけで試せるので、機密資料を用意する必要はありません。

目的：社内向けに、会議室の利用変更を知らせる。
読み手：同じ部署のメンバー。
材料：会議室Aは設備点検のため、11月2日の午前中は使えない。
形式：件名と、100字程度の本文。
条件：材料にない理由や、代わりの会議室を作らない。
分からない点は、確認事項として本文と分けて書く。

返答に「午後は必ず使える」「会議室Bへ移動してください」など、材料にない内容が加わっていないか確かめます。条件を書いても誤りは残りうるため、送る前の確認が必要です。

依頼の書き方を詳しく知るには、「何をしてほしいかを、どう伝えるか」へ。

迷ったときの調べ方

言葉の意味 → 用語辞典製品の違い → AI図鑑導入の確認 → 確認シート仕組みを深く知る → 全章一覧

社内で使えるデータや契約の条件は、社内の情報システム・セキュリティ・法務などの担当窓口へ確認してください。
