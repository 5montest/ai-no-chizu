## 通信の確認

A-8 は「実装したから安心」ではなく、通信の呼び出しがどこにも無いことを確かめて示す条件にした。次の grep がすべてである。

```
$ grep -rn "fetch(\|https\?://" --include=*.mjs --include=*.js --include=*.html .
app.js:85:      fetch('./data/faq.json'),
app.js:86:      fetch('./config.json'),
```

二件とも同じフォルダを読む `fetch` で、外部のホスト名は一つも出てこない。`cli.mjs` と `lib/` の中には `fetch` も URL も無い。APIキーを読む処理も、環境変数を読む処理も無い。

## 通過していない条件

いまのところ無い。ただし、この表が保証するのは「テストに書いた範囲」だけである。テストに書いていない使い方——たとえば「近い項目は選べたが、その本文が質問に答えていない」場合——は通る。この限界は README の「わかっている弱点」に書いた。
